# whkang-pages

A personal academic website built using the al-folio Jekyll theme.

## Local preview

```bash
gem install bundler
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.

## GitHub Pages deployment

This repository contains a GitHub Actions workflow for Pages deployment. Once the workflow completes, the site will be available at:

https://sloth-phd.github.io/whkang-pages

## Notes

The content is intentionally written as a clean academic starter template. Update the placeholder text and links with your own name, research interests, and publications.
