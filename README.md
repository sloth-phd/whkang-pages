# whkang-pages

A minimal Jekyll-based academic homepage for a personal website.

## Local preview

```bash
gem install bundler
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.

## GitHub Pages

This repository is designed to be published directly with GitHub Pages.

## Notes

The content here is a polished starter template based on an academic personal homepage pattern. Replace placeholder text, links, and PDFs with the exact site content you want to publish.
